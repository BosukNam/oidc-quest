# OIDC 퀘스트

마을을 돌아다니며 OIDC 로그인 흐름과 공격을 직접 겪어 보는 2D 탑뷰 어드벤처 게임입니다.

**플레이: https://bosuknam.github.io/oidc-quest/**

포털에 비밀번호를 알려 주지 않고 들어가는 방법, 즉 OIDC(소셜 로그인)의 핵심을 비유로 풀었습니다. 손님은 **신분증 발급소(SSO)** 에서 **도장 찍힌 입장권(ID 토큰)** 을 받아 오고, **포털 창구(백엔드)** 는 도장을 **도장 견본 게시판(JWKS)** 과 비교해 진짜인지 확인합니다. 게임 중에는 어려운 용어를 쓰지 않고, 장이 끝날 때 비유와 진짜 이름을 표로 보여 줍니다.

| 장 | 내용 | 진짜 이름 |
| --- | --- | --- |
| 1장. 입장권 받아 오기 | 번호표 받기 → 발급소에서 본인 확인 → 번호표 짝 맞추기 → 도장 비교 → 손목밴드 | state, OP, ID 토큰, JWKS, 세션 |
| 2장. 사기꾼 말로리 | 가짜 번호표, 이름만 고친 입장권, 도장 없는 입장권, 골목 게시판 견본 | 로그인 CSRF, 토큰 위조, alg:none, jku |
| 3장. 들어온 다음 | VIP 라운지는 안 돼요, 밴드가 만료됐어요 | 인증과 인가, 403과 401 |
| 보너스. 도장이 바뀐 날 | 새 도장이 오면 견본을 한 번 다시 보기 | 키 교체, JWKS 재조회 |

## 조작

- 휴대폰: 왼쪽 아래 조이스틱으로 이동, 오른쪽 아래 '대화' 버튼(옆에 대상이 있으면 노랗게 켜짐)
- 화면 끌기: 캐릭터에서 벗어나 지도의 다른 곳을 둘러봄. 걷기 시작하거나 '내 위치로'를 누르면 복귀
- 미니맵(오른쪽 위): 전체 지도, 파란 점이 나, 노란 점이 목표. 누르면 그곳을 봄
- 클릭 · 탭: 그 자리로 걸어감 (사람이나 게시판을 누르면 다가가서 대화)
- 방향키 · WASD: 한 칸 이동, Space · Enter: 대화 / 대사 넘기기
- 퀴즈·메뉴·장 완료 화면: 방향키로 옮기고 Space · Enter 로 고르기 (퀴즈는 숫자 1~4 도 가능)
- 노란 `!` 와 화면 가장자리 화살표가 다음 목적지를 알려 줍니다

## 구조

빌드 도구 없이 정적 파일만 씁니다.

- `index.html`, `style.css`: 화면과 HUD
- `game.js`: 타일맵 생성, BFS 길찾기, 고정 60Hz 루프, 대화와 선택지 엔진
- `quests.js`: 장·단계·대사·선택지 데이터. 새 시나리오는 여기에 단계를 추가하면 됩니다

로컬 실행: `python3 -m http.server` 후 http://localhost:8000
